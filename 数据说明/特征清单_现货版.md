---
title: 特征清单（85 个）
---

所有特征对齐到 XAU/USD 现货 1 分钟时间轴（北京时间，时间戳为分钟开始），只使用第 t 分钟及之前的数据。ATR14 为最近 14 根 K 线真实波幅的简单平均，与标签定义一致。GC 类特征来自 COMEX 黄金主力期货（换月按比例向前复权：只调整换月之后的价格，不让换月前的数据包含未来的换月跳空）。

另附 6 个非特征列：`raw_open`、`raw_high`、`raw_low`、`raw_close`（现货价格）和 `raw_atr14`，用于计算 triple-barrier 标签；`flag_degraded_day` 为 Databento 事后标记的数据质量下降日期，只用于筛选样本，不作为模型输入。

# 零、OHLC 逐分钟变化（4 个）

| 特征 | 计算方法 |
|---|---|
| `d_open` / `d_high` / `d_low` / `d_close` | (本分钟开盘价、最高价、最低价、收盘价 − 上一分钟收盘价) / ATR14 |

`d_close` 与 `ret_1` 几乎完全相同（相关系数 1.000），二者保留一个即可。

# 一、技术指标（只用现货 OHLC，36 个）

## 1. 趋势（13 个）

| 特征 | 计算方法 |
|---|---|
| `ma_dist_5` / `_15` / `_60` / `_240` | (收盘价 − N 分钟简单均线) / ATR14 |
| `ma_slope_5` / `_15` / `_60` / `_240` | N 分钟均线过去 5 分钟的变化 / ATR14 |
| `adx_14` | ADX(14) / 100，只衡量趋势强度（Wilder 平滑） |
| `di_diff_14` | (+DI − −DI) / 100，趋势方向 |
| `er_10` / `_30` / `_60` | Kaufman 效率比率：\|N 分钟净变动\| / N 分钟内每分钟变动绝对值之和 |

## 2. 动量（6 个）

| 特征 | 计算方法 |
|---|---|
| `ret_1` / `_5` / `_15` / `_60` | 过去 N 分钟对数收益率 / (ATR14 / 收盘价) |
| `rsi_14` | (RSI14 − 50) / 50，范围 −1 到 1（Wilder 平滑） |
| `macd_hist` | MACD 柱 (12, 26, 9) / 收盘价 × 10⁴ |

## 3. 波动率（5 个）

| 特征 | 计算方法 |
|---|---|
| `atr_rel` | ATR14 / 收盘价 × 10⁴（基点） |
| `vol_ratio_5_60` | ATR5 / ATR60，大于 1 表示波动在扩大 |
| `parkinson_30` | Parkinson 波动率（用最高价、最低价），30 分钟，× 10⁴ |
| `garman_klass_30` | Garman-Klass 波动率（用开高低收），30 分钟，× 10⁴ |
| `bb_width` | 布林带 (20, 2) 宽度 / 中轨 × 10⁴ |

## 4. 价格位置（8 个）

| 特征 | 计算方法 |
|---|---|
| `bb_pctb` | 布林带 %B：收盘价在布林带中的相对位置 |
| `donchian_pos_15` / `_60` / `_240` | (收盘价 − N 分钟最低价) / (N 分钟最高价 − 最低价) |
| `dist_high_60` / `_240` | (N 分钟最高价 − 收盘价) / ATR14 |
| `dist_low_60` / `_240` | (收盘价 − N 分钟最低价) / ATR14 |

## 5. K 线形态（4 个）

| 特征 | 计算方法 |
|---|---|
| `body_ratio` | (收盘价 − 开盘价) / (最高价 − 最低价) |
| `upper_shadow` | 上影线 / (最高价 − 最低价) |
| `lower_shadow` | 下影线 / (最高价 − 最低价) |
| `streak` | 连续同向 K 线数，上涨为正、下跌为负 |

# 二、时间特征（13 个）

| 特征 | 计算方法 |
|---|---|
| `tod_sin` / `tod_cos` | 美东时间一天中分钟数的正弦、余弦编码 |
| `sess_asia` / `sess_london` / `sess_ny` / `sess_overlap` | 交易时段：亚洲（其他时间）、仅伦敦（伦敦时间 08:00–16:30）、仅纽约（美东时间 08:00–17:00）、两者重叠 |
| `dow_mon` … `dow_fri` | 星期几，按 CME 交易日，独热编码 |
| `min_since_segment` | 距本连续区段开始的分钟数（断档超过 30 分钟算新区段） |
| `min_since_session` | 距本 CME 交易日开始的分钟数 |

# 三、成交量（GC，8 个）

| 特征 | 计算方法 |
|---|---|
| `gc_relvol_1` | log(1 + 当分钟成交量 / 过去 20 个交易日同一时刻的平均成交量) |
| `gc_relvol_5` / `_15` / `_60` | log(1 + 过去 N 分钟成交量 / 同时段历史平均) |
| `gc_volprice_5` / `_15` | 量价配合：sign(GC 过去 N 分钟收益) × `gc_relvol_N` |
| `gc_vwap_dist` | (GC 收盘价 − 当日 VWAP) / GC ATR14；VWAP 由逐笔成交精确计算 |
| `gc_poc_prev_dist` | (GC 收盘价 − 前一交易日 POC) / GC ATR14；POC 为成交最多的价位 |

# 四、订单流（GC，10 个）

| 特征 | 计算方法 |
|---|---|
| `gc_imb_1` | Delta / 成交量，买卖失衡比，−1 到 1 |
| `gc_cumimb_5` / `_15` / `_60` | 过去 N 分钟 Delta 之和 / 成交量之和 |
| `gc_div_15` / `_60` | Delta 背离：z(GC N 分钟收益 / ATR) − z(`gc_cumimb_N`)，z 为过去 1 天滚动标准化 |
| `gc_cumdelta_pos` | 当日累计 Delta 在当日最高值与最低值之间的位置 |
| `gc_avg_trade_15` | log(1 + 过去 15 分钟平均单笔成交手数) |
| `gc_large_share_15` | 过去 15 分钟大单（≥ 10 手）成交量占比 |
| `gc_large_imb_15` | 过去 15 分钟 (大单主动买 − 大单主动卖) / 大单成交量 |

# 五、盘口（GC 第一档，8 个）

| 特征 | 计算方法 |
|---|---|
| `gc_spread_mean` | 当分钟平均买卖价差，单位为跳（1 跳 = 0.1 美元） |
| `gc_spread_last` | 当分钟最后的买卖价差 |
| `gc_bookimb_mean` | 当分钟平均挂单失衡：(买一量 − 卖一量) / (买一量 + 卖一量) |
| `gc_bookimb_last` | 当分钟最后的挂单失衡 |
| `gc_bookimb_5` | 过去 5 分钟平均挂单失衡 |
| `gc_updates_rel` | log(1 + 盘口更新次数 / 过去 20 个交易日同一时刻的平均值) |
| `gc_buy_hit_depth_5` | log(1 + 过去 5 分钟主动买成交时卖一挂单量的平均值) |
| `gc_sell_hit_depth_5` | log(1 + 过去 5 分钟主动卖成交时买一挂单量的平均值) |

# 六、辅助信息 1：期现关系（4 个）

| 特征 | 计算方法 |
|---|---|
| `lead_ret_1` / `_3` / `_5` | (GC N 分钟对数收益 − 现货 N 分钟对数收益) / (现货 ATR14 / 收盘价) |
| `basis_dev_60` | (价差 − 过去 60 分钟价差中位数) / 标准差，截断到 ±10 |

# 七、辅助信息 2：数据状态（2 个）

| 特征 | 计算方法 |
|---|---|
| `cme_traded` | 这一分钟 GC 是否有成交；为 0 时 GC 类特征已填 0 |
| `roll_window` | 主力合约换月之后 2 个交易日内为 1（从换月发生的那一分钟开始） |
