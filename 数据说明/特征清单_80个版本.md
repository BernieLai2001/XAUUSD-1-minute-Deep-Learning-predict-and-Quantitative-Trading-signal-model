---
title: 特征清单（80 个）
---

全部特征只用 COMEX 黄金主力期货 GC（Databento GC.v.0），不使用现货价格。时间轴为 GC 有成交的 1 分钟 K 线（北京时间，时间戳为分钟开始），每个特征只使用第 t 分钟及之前的数据。

ATR14 为最近 14 根 K 线真实波幅的简单平均，与标签定义一致。换月按比例向前复权：只调整换月之后的价格，同一合约内的收益率与原始价格完全相同，换月前的数据不包含未来的换月跳空。

另附 8 个非特征列：`raw_open`、`raw_high`、`raw_low`、`raw_close`（GC 原始成交价，未复权）、`raw_atr14`（ATR14，美元）、`instrument_id`（当前合约），用于计算标签；`flag_degraded_day` 为 Databento 事后标记的数据质量下降日期，只用于筛选样本，不作为模型输入。

# 零、OHLC 逐分钟变化（4 个）

| 特征 | 计算方法 |
|---|---|
| `d_open` | (本分钟开盘价 − 上一分钟收盘价) / ATR14 |
| `d_high` | (本分钟最高价 − 上一分钟收盘价) / ATR14 |
| `d_low` | (本分钟最低价 − 上一分钟收盘价) / ATR14 |
| `d_close` | (本分钟收盘价 − 上一分钟收盘价) / ATR14 |

# 七、成交量（8 个）

| 特征 | 计算方法 |
|---|---|
| `gc_relvol_1` | log(1 + 当分钟成交量 / 过去 20 日同一时刻均量) |
| `gc_relvol_5` | log(1 + 过去 5 分钟成交量 / 同时段历史均量) |
| `gc_relvol_15` | log(1 + 过去 15 分钟成交量 / 同时段历史均量) |
| `gc_relvol_60` | log(1 + 过去 60 分钟成交量 / 同时段历史均量) |
| `gc_volprice_5` | 量价配合：sign(5 分钟收益) × gc_relvol_5 |
| `gc_volprice_15` | 量价配合：sign(15 分钟收益) × gc_relvol_15 |
| `gc_vwap_dist` | (收盘价 − 当日 VWAP) / ATR14（VWAP 由逐笔成交精确计算，换月时重新开始） |
| `gc_poc_prev_dist` | (收盘价 − 前一交易日 POC) / ATR14；POC 为成交最多的价位（换月后当天为 0） |

# 八、订单流（10 个）

| 特征 | 计算方法 |
|---|---|
| `gc_imb_1` | Delta / 成交量（买卖失衡比，−1 到 1） |
| `gc_cumimb_5` | 过去 5 分钟 Delta 之和 / 成交量之和 |
| `gc_cumimb_15` | 过去 15 分钟 Delta 之和 / 成交量之和 |
| `gc_cumimb_60` | 过去 60 分钟 Delta 之和 / 成交量之和 |
| `gc_div_15` | Delta 背离：z(15 分钟收益/ATR) − z(gc_cumimb_15)，z 为过去 1 天滚动标准化 |
| `gc_div_60` | Delta 背离：z(60 分钟收益/ATR) − z(gc_cumimb_60)，z 为过去 1 天滚动标准化 |
| `gc_cumdelta_pos` | 当日累计 Delta 在当日最高与最低之间的位置 |
| `gc_avg_trade_15` | log(1 + 过去 15 分钟平均单笔成交手数) |
| `gc_large_share_15` | 过去 15 分钟大单（≥10 手）成交量占比 |
| `gc_large_imb_15` | 过去 15 分钟大单买卖失衡：(大单主动买 − 大单主动卖) / 大单成交量 |

# 九、盘口（第一档）（8 个）

| 特征 | 计算方法 |
|---|---|

| `gc_sell_hit_depth_5` | log(1 + 过去 5 分钟主动卖成交时的买一挂单量均值) |
